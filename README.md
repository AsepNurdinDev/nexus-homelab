# NEXUS Homelab

Self-hosted infrastructure and DevOps laboratory covering Linux
administration, networking, security, containerization, observability,
CI/CD, and disaster recovery.

## Project Goals

- Build and maintain a self-hosted infrastructure
- Practice Linux system administration
- Design and manage network infrastructure
- Implement security hardening
- Deploy containerized applications
- Implement reverse proxy and secure remote access
- Build monitoring and centralized logging
- Implement CI/CD pipelines
- Implement automated backup and disaster recovery
- Document infrastructure decisions and operational procedures
